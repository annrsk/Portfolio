# Игра "Домино": Анализ и реализация

##  О проекте

Разработка классической игры "Домино" с полным циклом анализа, проектирования и тестирования. Демонстрация навыков системного анализа и технической реализации.

##  Моя роль

**Системный аналитик** — полный цикл работ:
- Формализация бизнес-требований в функциональные спецификации
- Декомпозиция сценариев использования (5 UC)
- Сравнительный анализ алгоритмов с обоснованием выбора
- Проектирование архитектуры (диаграммы состояний)
- Разработка методик структурного и функционального тестирования


### Сравнительный анализ алгоритмов

| Функция | Выбранный алгоритм | Обоснование |
|---------|-------------------|-------------|
| Игровой цикл | Простой циклический (O(n)) | Простота реализации, высокая производительность |
| Механика хода | Прямая проверка (O(1)) | Постоянное время выполнения, надежность |
| Доступные ходы | Линейный поиск (O(m)) | Оптимальная производительность, универсальность |
| Проверка победы | Базовые проверки | Быстрая, легкая модификация |

### Цикломатическая сложность

| Метод | Сложность | Интерпретация |
|-------|-----------|---------------|
| Matches | 2 | Низкая, легко тестируемый |
| Get_available_moves | 4 | Средняя, покрывает все ветвления |
| Make_move | 4 | Средняя, все пути протестированы |


##  Тестирование

### Структурное тестирование
- Построены потоковые графы для 3 ключевых методов
- Покрытие всех независимых путей выполнения
- Выявлена и устранена проблема: отсутствие валидации в `Make_move`

### Функциональное тестирование
- 5 сценариев использования
- 34 тестовых варианта
- 100% успешное прохождение
