# Обучение в школе 21

## SQL Bootcamp

Составление сложных запросов: Глубокое понимание и применение JOIN различных типов, вложенных подзапросов в FROM и SELECT.

Работа с наборами данных: Использование операторов множеств (UNION, INTERSECT, EXCEPT) для объединения, нахождения пересечений и разностей данных.

Фильтрация и сортировка: Фильтрация с помощью WHERE (включая работу с NULL, диапазонами дат), сложная сортировка по нескольким полям с разными направлениями (ORDER BY).

Аналитические запросы (OLAP): Использование конструкций GROUP BY и оконных функций (OVER, PARTITION BY) для агрегации данных и получения аналитических срезов.

Изменение данных: Использование команд INSERT, UPDATE, DELETE для добавления, изменения и удаления записей в таблицах.

Работа с транзакциями: Понимание транзакций и уровней изоляции для обеспечения целостности данных в многопользовательской среде.

Создание и управление схемой: Навык интеграции новых бизнес-фич в модель данных (создание таблиц, связей).

Индексация: Понимание принципов работы индексов, умение их создавать и знать, когда их применение необходимо для ускорения выполнения запросов.

Представления: Создание и управление представлениями (Views) и материализованными представлениями (Materialized Views) для упрощения сложных запросов, обеспечения безопасности и кэширования результатов.

## Бизнес-аналитика

Декомпозиция и понимание ЖЦ: Понимание полного жизненного цикла разработки (SDLC), ролей в команде и их функций. На практике применила навыки декомпозиции больших задач, выявления источников данных и структурирования информации (глоссарий).

Идентификация и управление стейкхолдерами: Владею техниками идентификации всех заинтересованных сторон (стейкхолдеров), анализа их влияния и интересов. Понимаю важность коммуникации и методы работы с разными группами стейкхолдеров.

Выявление и анализ требований: Научилась отличать типы требований (бизнес-требования, требования пользователя, функциональные). Строю контекстную диаграмму для определения границ системы, выявляю проблемы и потребности стейкхолдеров, формулирую бизнес-требования продукта.

Сбор требований: Применяю различные техники сбора требований (интервью, опросы, мозговые штурмы и др.) в зависимости от контекста задачи. Умею документировать полученные требования, строить функционально-ролевую модель (FRM).

Предметная область и информационное моделирование: Умею анализировать предметную область (domain), идентифицировать ключевые сущности и их атрибуты. Владею навыком построения Модели информации системы (System Information Model) и ее валидации с помощью CRUD-матрицы.

Визуальное моделирование (нотации UML): Свободно строю ключевые диаграммы для визуализации требований: Диаграмма потоков данных (DFD), Диаграмма состояний (State Machine Diagram), Диаграмма swimlane (разделения зон ответственности). Использую таблицы решений для описания сложной бизнес-логики.

Моделирование бизнес-процессов (BPMN 2.0): Владею нотацией BPMN для моделирования, анализа и регламентации бизнес-процессов. Умею выявлять inconsistencies (несоответствия) в процессах и оптимизировать их.

Работа с пользовательскими историями (User Stories): Умею формулировать требования в формате User Story (Как <Роль>, я хочу <Цель>, чтобы <Выгода>). Составляю четкие критерии приемки (Acceptance Criteria) и тестовые сценарии на их основе. Понимаю принципы обсуждения и backlog refinement.
