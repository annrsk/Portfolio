# Savushkin CRM API

RESTful API для системы управления взаимоотношениями с клиентами (CRM), разработанная для экосистемы "Савушкин продукт". Проект обеспечивает управление сотрудниками, клиентами и коммерческими предложениями с акцентом на целостность данных и бизнес-логику.

## 📋 О проекте

Этот API служит бэкендом для CRM-системы, позволяя управлять тремя основными бизнес-сущностями:

- **Сотрудники:** Отдел продаж, включая менеджеров и представителей
- **Клиенты:** Компании-партнеры с детальной информацией и закрепленным менеджером
- **Коммерческие предложения:** Коммерческие предложения для клиентов с отслеживанием сумм, сроков действия и ответственных сотрудников

Система обеспечивает ссылочную целостность (нельзя создать предложение для несуществующего клиента) и предоставляет endpoints для бизнес-аналитики.

## ✨ Ключевые возможности

- **Полный CRUD:** Стандартные операции создания, чтения, обновления и удаления для всех трех сущностей
- **Автоматическая документация API:** Интерактивный Swagger UI (`/docs`) и ReDoc (`/redoc`), генерируемые FastAPI
- **Валидация данных:** Pydantic-модели (`models.py`) обеспечивают проверку всех входящих данных
- **Ссылочная целостность:** Проверка существования внешних ключей перед созданием или обновлением записей
- **Контейнеризация:** Полная настройка Docker Compose для развертывания PostgreSQL и FastAPI одной командой
- **Бизнес-логика:** Эндпоинт для выявления топ-сотрудников по количеству созданных коммерческих предложений

## 🗄 Схема базы данных

Реляционная схема, отражающая бизнес-структуру:

```sql
-- Таблица сотрудников (основа)
CREATE TABLE employees (
    id SERIAL PRIMARY KEY,
    full_name TEXT NOT NULL,
    position TEXT, 
    department TEXT, 
    email TEXT, 
    phone TEXT
);

-- Таблица клиентов (связь с ответственным менеджером)
CREATE TABLE clients (
    id SERIAL PRIMARY KEY,
    company_name TEXT NOT NULL, 
    inn TEXT, 
    address TEXT,
    client_type TEXT, 
    status TEXT,
    responsible_manager_id INTEGER REFERENCES employees(id)
);

-- Таблица коммерческих предложений (связь с клиентом и сотрудником)
CREATE TABLE commercial_offers (
    id SERIAL PRIMARY KEY,
    client_id INTEGER REFERENCES clients(id),
    created_at TIMESTAMP DEFAULT NOW(),
    valid_until TIMESTAMP, 
    total_amount INTEGER, 
    status TEXT,
    created_by INTEGER REFERENCES employees(id)
);
