# Кейс 1 – приложение Habit Flow
---
Концепт:
Веб-приложение, которое объединяет классический менеджер задач (Todo-list) с трекером привычек. Уникальность — в системе «Потоков», где повторяющиеся задачи и привычки автоматически попадают в ежедневный планировщик с учетом приоритета, дедлайнов и вашей ежедневной загруженности.

Основная ценность – избавить пользователя от необходимости ежедневно вручную составлять план на день. Приложение предлагает готовый реалистичный план, основываясь на привычках, целях и дедлайнах пользователя.
