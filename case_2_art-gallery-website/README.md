# Art Gallery Website

Веб-приложение для художественной галереи с возможностью отправки контактных данных и просмотра информации о выставках и произведениях искусства.

##  О проекте

Проект представляет собой информационный сайт художественной галереи с функционалом сбора контактной информации потенциальных клиентов и художников. Реализован с использованием Flask и SQLite, предоставляет административный интерфейс для просмотра собранных контактов.

##  Технологический стек

| Компонент | Технология |
|-----------|------------|
| Backend | Flask 3.1.2 |
| База данных | SQLite |
| Frontend | HTML, CSS |

## Заключение
Проект демонстрирует навыки:

- Разработки веб-приложений на Flask
- Проектирования REST API
- Работы с ORM (SQLAlchemy)
- Интеграции фронтенда и бэкенда
- Обработки форм и валидации данных
